# Phase 5 — Team Retrospective

## Goal

Evaluate how the team worked using observable evidence from GitHub and the project.

## No product coding

Only minimal documentation corrections are allowed. Feature work is closed.

## Review evidence

- Issues planned vs completed;
- PR sizes and review turnaround;
- review comments that caught defects/design problems;
- CI failures and causes;
- merge conflicts and resolution quality;
- defects discovered after merge;
- blockers and when they were surfaced;
- ADR quality and decision turnaround;
- AI-generated code issues/successes;
- unplanned scope added/avoided.

## Outcome

Complete `templates/RETROSPECTIVE.md` and record 3–5 concrete process changes for the next project.
