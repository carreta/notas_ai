# Phase 0 — Foundation

## Goal

Create a reproducible repository and collaboration baseline without implementing product functionality prematurely.

## In scope

- Laravel project boots from clean checkout/setup instructions.
- Environment example contains required variable names without secrets.
- Test baseline runs.
- Formatter baseline established.
- Build baseline established if frontend assets are used.
- CI baseline created.
- Kickoff team decisions resolved: TD-007, TD-008, TD-012, TD-013, TD-014, TD-015.
- GitHub branch protections/settings documented/applied where account permissions allow.
- Non-sensitive sample meeting fixture added.

## Out of scope

- real AI provider calls;
- meeting-analysis orchestration;
- results/history features.

## Exit criteria

- application boots;
- baseline tests pass;
- build passes if applicable;
- clean migration succeeds;
- CI executes on PR;
- resolved decisions recorded;
- no secret committed.
